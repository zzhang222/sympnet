# SympNets universal approximation, formalized in Lean 4

A Lean 4 + Mathlib formalization of **Theorem 5** (universal approximation for G-SympNets) of

> P. Jin, Z. Zhang, A. Zhu, Y. Tang, G. E. Karniadakis,
> *SympNets: Intrinsic structure-preserving symplectic networks for identifying Hamiltonian
> systems*, [arXiv:2001.03750](https://arxiv.org/abs/2001.03750) (v3).

## Main result

```lean
theorem SympNet.G_SympNet_universal_unconditional {d : ℕ} (r : ℕ) (hr : 1 ≤ r)
    (σ : ℝ → ℝ) (hσ : RFinite r σ) (U : Set (X d)) (hU : IsOpen U) (hUc : Convex ℝ U) :
    UDense r U (GSympNet σ) {F | F ∈ SP r U ∧ Set.InjOn F U}
```

For `r ≥ 1`, an open **convex** `U ⊆ ℝ^{2d}` and an r-finite activation `σ`, G-SympNets are
`C^r`-dense on compacta in the **injective** `C^r` symplectic maps on `U`. No hypotheses, no
`sorry`; `#print axioms` gives only `[propext, Classical.choice, Quot.sound]`.

The paper states the theorem for all of `SP^r(U)` and arbitrary open `U`; that version is false
(G-SympNets are injective). See `Sympnet/Counterexample.lean` (`paper_theorem5_false`). The
error is in the paper's Lemma 4, which overstates Turaev's theorem.

Both results the paper cites without proof are proved here:
* **Lemma 2 (Hornik–Stinchcombe–White)**: `SympNet.hornikDensity`.
* **Lemma 4 (Turaev), convex/injective form**: `SympNet.turaevHenon`, via
  `SympNet.turaevShear` (smooth symplectic diffeomorphisms of ℝ^{2d} are `C^r`-approximated by
  finite compositions of gradient shears / Hénon maps) and `SympNet.symplecticApprox`
  (`C^r` injective symplectic maps on convex sets are approximated by global smooth symplectic
  diffeomorphisms).

## Layout

| Path | Content |
|---|---|
| `Sympnet/SympNetUniversal.lean` | Definitions (SP^r, C^r closeness, G-SympNets, Hénon maps), Lemma 3, composition stability, `G_SympNet_universal` from Lemmas 2 and 4 |
| `Sympnet/Counterexample.lean` | The paper's Lemma 4 / Theorem 5 are false as stated |
